# Welcome Center

The Welcome Center is the interactive first-login entry point of HorneroOS:
eight short sections that teach the system from inside the system. It opens
automatically on login until switched off, and stays available as a reference
afterwards. Design decisions live in `docs/adr/001-welcome.md`.

## Opening it

| Path | How |
| ---- | --- |
| Automatic | Once per login session while `showOnLogin` is on |
| Launcher | Search “Hornero Welcome” (`assets/hornero-welcome.desktop`) |
| Control Center | System pane → “Hornero Welcome” tile |
| CLI | `horneroctl welcome open [page]` (asks the running shell over IPC) |
| IPC | `qs ipc call welcome open [page]` · `close` · `status` |

Valid pages: `start`, `navigate`, `shell`, `workspaces`, `personalize`,
`tools`, `system`, `learn`. Unknown pages open `start` with a warning.

## Opting out

Untick “Show on login” in the window footer (or
`horneroctl welcome set-show-on-login false --yes`). The shell keeps the
choice in memory and persists it through `horneroctl`; if the write fails,
the footer shows a warning and the preference holds for the session.

## Content model

- Pages (`modules/welcome/pages/*.qml`) describe and trigger only. They may
  call `Actions.*`, `ShortcutHints.*` and `Welcome.*` — nothing else.
- `modules/welcome/Actions.qml` is the allowlist: launcher, dashboard,
  session menu, utilities drawer, layout picker, Control Center panes
  (validated against `PaneRegistry`), terminal (via the launcher's app2unit
  shape), and Welcome navigation. No URLs, no generic spawning.
- Shortcut badges resolve at runtime from
  `$XDG_DATA_HOME/hornero/shortcuts.json` (generated by HorneroOS/config
  `scripts/generate-shortcuts.py`). Unknown or missing ids render **no
  badge** — never a wrong shortcut.

## Curated shortcuts

Badges below are the stock-config defaults; users may rebind them, and the
window always shows the live binding.

| Manifest id | Stock keys | Shown on |
| ----------- | ---------- | -------- |
| `exec-launcher` | CTRL + Space | Start, Navigate |
| `ipc-dashboard-toggle` | SUPER + D | Navigate |
| `scrolloverview-overview:toggle` | SUPER + O | Navigate |
| `app-terminalemulator` | SUPER + Return | Shell |
| `exec-kitty` | SUPER + E | Shell |
| `workspace:1` | SUPER + 1 | Workspaces |
| `movetoworkspace:1` | SUPER + SHIFT + 1 | Workspaces |
| `togglespecialworkspace:magic` | SUPER + S | Workspaces |
| `exec-screenshooter` | Print | Tools |
| `exec-clipboard` | SUPER + V | Tools |
| `exec-power-menu` | SUPER + X | Tools |
| `ipc-lock-lock` | SUPER + L | System |
| `exec-keyboard-help` | SUPER + slash | Learn |

All thirteen curated ids are exercised by at least one card.

## State

`$XDG_STATE_HOME/hornero/welcome/state.json`, owned by HorneroOS/hornero
(`horneroctl welcome ...`). The shell reads it directly and writes only
through the CLI. Session markers live under `$XDG_RUNTIME_DIR` and vanish
on logout. See `docs/IPC.md` for the `welcome` IPC target.
