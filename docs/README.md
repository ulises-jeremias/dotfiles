# Repository documentation

This folder contains contributor and workstation-source notes. It is not the
canonical user manual for HorneroOS; current product behavior is published at
[hornero-os.vercel.app/docs](https://hornero-os.vercel.app/docs).

The `wiki/` directory is a historical archive of the earlier personal
workstation setup. Its commands and paths are not supported HorneroOS
interfaces. Useful guidance is being rewritten into the official product
documentation.

Architecture records retained under `adrs/` describe only current decisions.
Superseded records and implementation migration plans were removed after their
work landed.
